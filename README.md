# Portfolio de Jorge Luis Villegas Oliva

Sitio personal publicado en GitHub Pages: https://jlvillegas.github.io/portfolio/

HTML, CSS y JavaScript sin dependencias ni paso de compilación. Tiene tema claro y oscuro, y un tablero que comprueba al cargar si los sitios publicados responden.

## Qué muestra

- Sistema de gestión de la Clínica Villegas: agenda, historia clínica, cobros con Mercado Pago, sala de espera con voz y dictado con IA. El código es privado; hay una demo con datos inventados.
- Sitios web publicados en Netlify.
- AI Lead Qualifier, un flujo de n8n con Gemini: [repositorio](https://github.com/jlvillegas/ai-lead-qualifier).
- Instalaciones de redes, Starlink y cámaras con Villegas Insumos Tecnológicos.

## Ver en local

Abrir `index.html` en el navegador, o servir la carpeta con `python3 -m http.server`.
